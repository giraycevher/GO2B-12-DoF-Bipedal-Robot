# Security Policy

The following versions of GO2B-12-DoF-Bipedal-Robot are currently supported with security updates.

| Version       | Supported  |
| -------       | -----|
| Main (latest) | ✅  |
| Older releases | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

### How to Report

- Open a private issue or contact the maintainer directly.
- GitHub Issues can be used for non-sensitive security concerns.
- For sensitive vulnerabilities, please contact the maintainer before public disclosure.

### Contact

Maintainer: Giray Cevher

GitHub: https://github.com/giraycevher

### Response Process

After a vulnerability report is received:

1. The report will be reviewed and acknowledged within 7 days.
2. The vulnerability will be evaluated and reproduced if possible.
3. A fix will be developed and tested.
4. The reporter will be informed about the resolution status.
5. If accepted, the fix will be included in a future update and credited when appropriate.

### Disclosure Policy

Please do not publicly disclose security vulnerabilities until they have been investigated and addressed.

Thank you for helping improve the security of the GO2B-12-DoF-Bipedal-Robot project.
